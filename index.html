3. 분석 결과
상품을 선택하면 자동 계산
위에서 상품을 선택하면 계산 결과가 여기에 표시됩니다.
이 표의 목적: 모든 쿠폰(A+B) 적용했을 때 목표가(플랫폼 최저가/공홈 판매가/공홈+3,500)와 같거나 그 이상이 되려면 세팅가가 얼마여야 하는지 역산.

계산 공식
· 세팅가(제출가) = 사장님이 각 상품별 입력 (기본값 = 플랫폼 최저가)
· 에이블리 쿠폰 할인 (A) = 세팅가에 맞는 tier(최소 주문금액 만족 최상위) 자동 적용
· 중복 쿠폰 할인 (B) = 1차 쿠폰 적용된 가격에 매칭 (셀러 100% 부담)
· 쿠폰 적용가 = 세팅가 − A − B
· 셀러 쿠폰 부담금 = min(A × ½, 세팅가 × 5%) + B
· 에이블리 지원금 = (A + B) − 셀러 쿠폰 부담금
· 수수료 = 실매출 × 27.5% (실매출 = 세팅가 − min(A×½, 세팅가×5%) − B)
· 최종 이익 = 실매출 − 2,699원 − 수수료
· 3개 기준가 컬럼 = "이 기준을 하회하지 않으려면 필요한 세팅가" (클릭하면 세팅가에 적용). 아래 작은 글씨는 원래 기준가.
· 빨간 행 = 쿠폰 적용가 < 플랫폼 최저가 (플랫폼 최저가 위반 위험)
